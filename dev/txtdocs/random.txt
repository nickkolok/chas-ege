.iz() - Если p1 опущено, возвращает случайный элемент массива, иначе последовательность p1 неповторяющихся элементов массива/
Без аргумента: возвращает один случайный элемент массива.
С числом n: возвращает массив из n уникальных случайных элементов (без повторений).
можно использовать чтобы выбрать случайную формулировку, объект, цвет, глагол и т.д. или чтобы взять несколько разных вариантов из списка.
Пример использования:
Один случайный элемент
let verb = ['бежать', 'плыть', 'лететь'].iz(); //"плыть"
Два разных элемента
let colors = ['красный', 'синий', 'зелёный', 'жёлтый'].iz(2); //['зелёный', 'красный']
Использование в тексте
text += 'Выберите ' + ['фигуру', 'график', 'диаграмму'].iz() + '.';


slKrome(exclude, min, max[, step]) — случайное число, кроме запрещённых
Генерирует случайное число в диапазоне [min, max], исключая:одно значение например (5), массив значений ([2, 4, 6]), значения, удовлетворяющие условию (x => x % 3 === 0).
используем чтобы избежать дубликатов или чтобы исключить вырожденные случаи (деление на ноль, полные квадраты и т.д.).
Пример использования:
Исключить одно число
let a = slKrome(5, 1, 10); //любое от 1 до 10, кроме 5
Исключить массив
let b = slKrome([0, 1, -1], -5, 5); //например, 3
Исключить по условию
let c = slKrome(x => x.isPolnKvadr(), 1, 50); //не 1, 4, 9, 16, 25, 36, 49
Полезно в геометрии
let angle = slKrome(90, 30, 150); //угол ≠ 90°(не прямоугольный)



sluchDel - Случайный делитель числа a
Возвращает случайный положительный делитель числа a.
Пример использования:
let n = 60;
let d = sluchDel(n); //1, 2, 3, 4, 5, 6, 10, 12, 15, 20, 30 или 60
Генерация сократимой дроби
let num = sluchDel(100);   // например, 25
let den = sluchDel(100);   // например, 50
//дробь 25/50 = 1/2
Работает только с целыми положительными числами.



.zapslch(from, to, min, max[, step])  заполняет срез массива случайными числами. 
Заполняет элементы массива с индекса from по to случайными значениями из диапазона.
Используем для быстрого создания массива коэффициентов, или при генерации координат точек.
Пример использования:
let arr = [];
arr.zapslch(0, 4, 1, 10); // → [3, 7, 1, 9, 5]
Координаты 3 точек (x, y)
let points = [];
points.zapslch(0, 5, -5, 5); // → [-2, 4, 1, -3, 0, 5]
//точки: (-2,4), (1,-3), (0,5)



.pm() - Случайным образом возвращает число или ему противоположное.
другими словами С равной вероятностью возвращает число или его противоположное: 5.pm() тогда 5 или -5.
Пример использования:
let a = sl(1, 5).pm(); // → -3, 2, -1 и т.д.
//Уравнение: ±2x ± 5 = 0
text += `$${a}x ${b.pm()} = 0$`;



shuffle - Перемешивает элементы массива на месте (изменяет исходный массив).
Если передать true, перемешивает рекурсивно (вложенные массивы тоже).
Пример использования:
let answers = ['верно', 'неверно', 'зависит'].shuffle();
Перемешать пары
let pairs = [['A', 1], ['B', 2], ['C', 3]].shuffle();
Рекурсивное перемешивание (редко нужно)
let matrix = [[1,2], [3,4], [5,6]].shuffle(true);



shuffleJoin - Перемешивает массив и сразу соединяет элементы строкой с разделителем. Для генерации выражений: AB + AC, AC + AB и т.д.
Пример использования:
let vectors = ['\\overrightarrow{AB}', '\\overrightarrow{AC}'];
text += vectors.shuffleJoin(' + '); // → "$\overrightarrow{AC} + \overrightarrow{AB}$"
Случайный порядок в сумме
let terms = ['x^2', '2x', '1'].shuffleJoin(' + ');
//"2x + 1 + x^2"
