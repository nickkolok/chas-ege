.iz() - Если p1 опущено, возвращает случайный элемент массива, иначе последовательность p1 неповторяющихся элементов массива
Принцип работы:
Array.prototype.iz=function(p1){
	if(p1)
		return sluchiz(this,p1);
	else
		return this[sl(0,this.length-1)];
}
Пример использования:
var drive = ['едь', 'ехай', 'ехайте'].iz();
или ещё можно:
var drive = ['едь', 'ехай', 'ехайте'].iz(2);



slKrome() - Случайное число, кроме a:
если a - массив, то не содержащееся в нём;
если a - число или строка, то не равное ему;
если a - функция, принимающая параметр - то не удовлетворяющее ей (т. е. чтобы функция вернула 0, false, undefined и т.д.)
	пример использования с функцией:
	slKrome(function(x){return x.isPolnKvadr()}, 1, 100) - случайное число от 1 до 100, не являющееся полным квадратом.
Принцип работы:
function slKrome(a,p1,p2,p3){
	var b;

	if(a.isNumber || a.isString){
		for(let i = 0; i < 1000000; i++){
			b=sl(p1,p2,p3);
			if(b!=a){
				return b;
			}
		}
		throw "Too hard restrictions for slKrome()";
	}else if(a.isArray){
		if(!a.length){
			return sl(p1,p2,p3);
		}
		for(let i = 0; i < 1000000; i++){
			b=sl(p1,p2,p3);
			if(!a.hasElem(b)){
				return b;
			}
		}
		throw "Too hard restrictions for slKrome()";
	}else if(a.isFunction){
		for(let i = 0; i < 1000000; i++){
			b=sl(p1,p2,p3);
			if(!a(b)){
				return b;
			}
		}
		throw "Too hard restrictions for slKrome()";
	}else
		console.error('Первый параметр функции slKrome должен быть числом, строкой, массивом или функцией.');
	return b;
}
Пример использования: var x2=slKrome([0,1,-1],-10,10,1);

shuffle - Перемешивает массив случайным образом. Если b, то ещё и рекурсивно на один уровень.
Принцип работы:
Array.prototype.shuffle = function(b){
	var i = this.length, j, t;
	while(i)
	{
		j=((i--)*Math.random() ).floor();
		t=b && typeof this[i].shuffle!=='undefined' ? this[i].shuffle() : this[i];
		this[i]=this[j];
		this[j]=t;
	}
	return this;
};
Пример использования: ['\\sin^2','\\ctg']].iz().shuffle()



sluchiz - Массив n случайных неповторяющихся элементов массива a
Пример работы:
function sluchiz(a,n){
	if(!(n>=1))
		n=1;
	var b=a.slice();
	b.shuffle();
	b.length=n;
	return b;
}
Пример использования: var a=sluchiz([20,25,40,80,100,125])[0];



shuffleJoin - Перемешивает и соединяет массив
Пример работы:
Array.prototype.shuffleJoin = function (separator){
	separator = separator || '';
	return this.shuffle().join(separator);
}
Пример использования:
let rand = sl1();
['\\overrightarrow{AB}', '\\overrightarrow{AC}'].shuffleJoin(['+', '$ и $'][rand])
