sklonlxkand - Преобразует строку-существительное (или массив таких строк) в объект Word, содержащий все формы слова в 12 падежах.
ie: именительный	падеж единственного	числа
re: родительный		падеж единственного	числа
de: дательный		падеж единственного	числа
ve: винительный		падеж единственного	числа
te: творительный	падеж единственного	числа
pe: предложный		падеж единственного	числа
im: именительный	падеж множественного	числа
rm: родительный		падеж множественного	числа
dm: дательный		падеж множественного	числа
vm: винительный		падеж множественного	числа
tm: творительный	падеж множественного	числа
pm: предложный		падеж множественного	числа
Если слово уже есть в словаре (lx), возвращает готовый Word, если нет, то пытается определить основу по суффиксу и клонирует шаблон склонения. Поддерживает рекурсивную обработку массивов.
Пример работы:
Простое склонение
let konf = sklonlxkand('конференция');
text += 'на ' + konf.pe; //"на конференции"
Случайный выбор из списка
let event = sklonlxkand(['фестиваль', 'слёт', 'мероприятие'].iz());
text += 'во время ' + event.re; //"во время фестиваля"
Массив сразу
let items = sklonlxkand(['ручка', 'тетрадь', 'линейка']);
text += 'купил ' + items[0].ve + ', ' + items[1].ve + ' и ' + items[2].ve;
// "купил ручку, тетрадь и линейку"




chislitlx(число, существительное) - числительное + существительное, Возвращает корректно согласованную фразу вида: «5 дней», «23 метра», «102 конференции».
Автоматически выбирает нужную форму существительного в зависимости от числа.  Возвращает строку, состоящую из данного числа и подходящего падежа слова p1, при этом
полученное словосочетанию стоит в падеже p2 (если не указан - именительный).
Используем в основной массе его. 
number — число (целое или дробное),
noun — слово (строка или результат sklonlxkand),
case — желаемый падеж:
'i' — именительный (по умолчанию),
'r' — родительный,
'd' — дательный,
'v' — винительный,
't' — творительный,
'p' — предложный.
Можно добавить $ в case, чтобы число отображалось в LaTeX: chislitlx(5, 'день', '$i') → $5$ дня
Крайне редко, но может появляться adj - для прилагательного, и тогда фраза будет отоброжаться как «$5$ розовых кукол»:
let adj = 'розовый';
let noun = 'кукла';
chislitlx(5, noun, '$',adj)
Ещё примеры:
let days = sl(2, 10);
text += 'длится ' + chislitlx(days, 'день') + '.'; 
//"длится 7 дней."

let books = 21;
text += 'купил ' + chislitlx(books, 'книга', 'v') + '.';
//"купил 21 книгу."

let points = 100;
text += 'за ' + chislitlx(points, 'балл', '$r') + '.';
//"за $100$ баллов."



chislitM - Вспомогательная функция для chislitlx. Редко используется напрямую.
Выбирает форму слова по правилу:
если число оканчивается на 1 (но не 11) → s1 («1 день»),
если на 2–4 (но не 12–14) → s2 («2 дня»),
иначе → s5 («5 дней»).
Пример использования: 
Ручное согласование
let dist = 1500;
text += 'проехал ' + chislitM(dist, 'метр', 'метра', 'метров');
//"проехал 1500 метров"
С LaTeX
text += 'на расстоянии ' + chislitM(3, 'километр', 'километра', 'километров', true, false);
//"на расстоянии $3$ километра"



chislit - Только выбирает форму слова, без форматирования числа.
Используется, когда нужно согласовать глагол или другую часть речи
Пример использования:
let n = 3;
text += chislit(n, 'имеет', 'имеют', 'имеют'); 
//"имеют"
let k = 1;
text += 'это значит, что ' + k + ' ' + chislit(k, 'участник пришёл', 'участника пришли', 'участников пришли');
//"это значит, что 1 участник пришёл"



declensionOfAdjectives - Склонение прилагательных с числительными. Согласует прилагательное с числительным в родительном падеже множественного числа:
«5 красных шариков», «12 синих ручек».
Пример использования:
let color = 'красный';
let count = 7;
text += chislitlx(count, declensionOfAdjectives(count, color) + ' шарик');
//"7 красных шариков"
 Или проще:
let adj = declensionOfAdjectives(3, 'зелёный');
text += 'купил 3 ' + adj + ' яблока'; 
//"купил 3 зелёных яблока"
