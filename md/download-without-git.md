# Как скачать проект, если не работает `git clone`

В некоторых случаях (например, при проблемах с сетью, файрволами или в изолированных средах) команда `git clone` может не работать. Вот альтернативный способ получить код проекта.

## Способ 1: Скачать ZIP-архив через браузер

1. Откройте страницу репозитория на GitHub
2. Нажмите на кнопку "Code" (зеленая кнопка)
3. Выберите "Download ZIP"
4. Распакуйте архив в нужную директорию

## Важные замечания

- При скачивании ZIP-архива вы не получаете историю коммитов Git
- Для работы с проектом вам нужно будет инициализировать Git вручную: git init
- Если вам нужна полная история, попробуйте настроить git clone через прокси или другие методы

## Проблема с User-Agent

Иногда GitHub блокирует запросы без корректного User-Agent. Если скачивание через curl или wget не работает, добавьте заголовок User-Agent.
