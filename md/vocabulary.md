# Склонение слов и числительных

В этом справочнике описаны функции для работы с русским языком: склонение существительных, согласование числительных с существительными и прилагательными. Это нужно, чтобы условия задач звучали грамотно (например, «5 дней», «23 метра», «102 конференции»).


## `sklonlxkand()` — склонение существительных

Преобразует строку-существительное (или массив таких строк) в объект Word, содержащий все формы слова в 12 падежах.
- **Единственное число:** `ie` (именительный), `re` (родительный), `de` (дательный), `ve` (винительный), `te` (творительный), `pe` (предложный).
- **Множественное число:** `im` (именительный), `rm` (родительный), `dm` (дательный), `vm` (винительный), `tm` (творительный), `pm` (предложный).
Если слово уже есть в словаре (lx), возвращает готовый Word, если нет, то пытается определить основу по суффиксу и клонирует шаблон склонения. Поддерживает рекурсивную обработку массивов.
**Пример использования:**

```javascript
// Простое склонение
let konf = sklonlxkand('конференция');
text += 'на ' + konf.pe; //"на конференции"
// Случайный выбор из списка
let event = sklonlxkand(['фестиваль', 'слёт', 'мероприятие'].iz());
text += 'во время ' + event.re; //"во время фестиваля"
// Массив сразу
let items = sklonlxkand(['ручка', 'тетрадь', 'линейка']);
text += 'купил ' + items[0].ve + ', ' + items[1].ve + ' и ' + items[2].ve;
// "купил ручку, тетрадь и линейку"
```





## `chislitlx(число, существительное[, падеж])` — числительное + существительное

Возвращает корректно согласованную фразу вида «5 дней», «23 метра», «102 конференции».
Автоматически выбирает нужную форму существительного в зависимости от числа. Используется в большинстве случаев, когда нужно вывести число с подписью.
**Аргументы:**
- `number` — число (целое или дробное),
- `noun` — слово (строка или результат `sklonlxkand`),
- `case` — желаемый падеж (по умолчанию `'i'` — именительный):
  - `'i'` — именительный
  - `'r'` — родительный
  - `'d'` — дательный
  - `'v'` — винительный
  - `'t'` — творительный
  - `'p'` — предложный
Можно добавить `$` в `case`, чтобы число отображалось в LaTeX: `chislitlx(5, 'день', '$i')` → `$5$ дня.
Крайне редко может появляться `adj` — для прилагательного, тогда фраза будет отображаться как «$5$ розовых кукол».

// С прилагательным
let adj = 'розовый';
let noun = 'кукла';
chislitlx(5, noun, '$', adj);
```
**Пример использования:**

```javascript
let days = sl(2, 10);
text += 'длится ' + chislitlx(days, 'день') + '.'; 
// "длится 7 дней."


let books = 21;
text += 'купил ' + chislitlx(books, 'книга', 'v') + '.';
// "купил 21 книгу."


let points = 100;
text += 'за ' + chislitlx(points, 'балл', '$r') + '.';
// "за $100$ баллов."




## `chislitM(число, s1, s2, s5)` — выбор формы слова по правилу

Вспомогательная функция для `chislitlx`, редко используется напрямую. Выбирает форму слова по правилу:
- если число оканчивается на 1 (но не 11) → `s1` («1 день»),
- если на 2–4 (но не 12–14) → `s2` («2 дня»),
- иначе → `s5` («5 дней»).
**Пример использования:**

```javascript
// Ручное согласование
let dist = 1500;
text += 'проехал ' + chislitM(dist, 'метр', 'метра', 'метров');
// "проехал 1500 метров"

// С LaTeX
text += 'на расстоянии ' + chislitM(3, 'километр', 'километра', 'километров', true, false);
// "на расстоянии $3$ километра"
```




## `chislit(n, f1, f2, f5)` — только выбор формы слова

Только выбирает форму слова, без форматирования числа. Используется, когда нужно согласовать глагол или другую часть речи.
**Пример использования:**

```javascript
let n = 3;
text += chislit(n, 'имеет', 'имеют', 'имеют'); 
// "имеют"

let k = 1;
text += 'это значит, что ' + k + ' ' + chislit(k, 'участник пришёл', 'участника пришли', 'участников пришли');
// "это значит, что 1 участник пришёл"
```




## `declensionOfAdjectives()` — склонение прилагательных с числительными

Согласует прилагательное с числительным в родительном падеже множественного числа: «5 красных шариков», «12 синих ручек».
**Пример использования:**

```javascript
let color = 'красный';
let count = 7;
text += chislitlx(count, declensionOfAdjectives(count, color) + ' шарик');
// "7 красных шариков"


// Или проще:
let adj = declensionOfAdjectives(3, 'зелёный');
text += 'купил 3 ' + adj + ' яблока'; 
// "купил 3 зелёных яблока"
```
