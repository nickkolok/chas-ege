# Создаём новый шаблон

## Общие принципы

### DRY - Don't Repeat Yourself

Если нужна какая-то функция, которая кажется стандартной -
скорее всего, где-то в библиотеке она уже есть готовая.
Нужно просто поискать.

### Принцип обобщения

Смысл шаблона не в том, что он в сжатом виде хранит задачи-образцы,
а в том, что он обобщает задачи-образцы,
позволяя получать сотни и тысячи аналогичных задач.

Как правило, обобщение предпочтительнее перечисления.
Например, если нам нужно чётное положительное число,
не превосходящее 10 и при этом не являющееся полным квадратом,
не надо писать:
```js
let n = [2, 6, 8, 10].iz();
```
Лучше написать:
```js
let n = slKrome(isPolnKvadr, 2, 10, 2);
```
*Потому что однажды потребуется расширить диапазон до 20...*


## Определяем номер

Имя шаблона - это всегда целое число в десятичной системе счисления.
Как правило, в проекте используются номера из СдамГИА (бывшего РешуЕГЭ),
а также Открытого банка заданий (Обзад).

## `set*Task({...})`

Это функции, отвечающие за собственно создание задания.

## Модификаторы

Это функции, которые изменяют или дополняют текст задания и решение после создания.

Все `set*Task({...})` и модификаторы определяются в `src/chas2/task.js`.

`chas2.task` и `NAtask` - это одно и то же.
Нельзя только смешивать их в одном шаблоне!


## Механизм предпочтений (`preference`).

Мы используем `preference` в случае, когда один шаблон может генерировать несколько родственных типов задач.
Например, задачи вида
"Дана сторона квадрата, найдите его площадь"
и
"Дана сторона квадрата, найдите его периметр"
могут быть отнесены к одному шаблону,
но тогда необходимо предусмотреть `preference`,
позволяющий генератору принудительно переключать шаблон на один из вопросов.
Если `preference` не задан извне, шаблон использует случайный выбор.

Для получения `preference` используется функция `getSelectedPreferenceFromList(key, preference)`.
Использование `getListedPreference()` считается устаревшим и категорически не рекомендуется.
Весь массив `preference` необходимо передавать в `setTask({})` (см. файлы-примеры, указанные ниже).

Пример из ЕГЭ [про перевод температур](../zdn/matege2024b/4/509729.js) :
```javascript
let key = '509729';
let preference = ['CelToFar', 'FarToCel']; // Из Цельсия в Фаренгейт или наоборот
let rand = getSelectedPreferenceFromList(key, preference);

let degreeName = ['Цельсия', 'Фаренгейта'][rand];
```

Пример из ОГЭ [про числовые прямые](../zdn/matege2024b/4/311392.js) :

```javascript
let key = '311392';
let preference = ['hideNumbers', 'showNumbers']; // Скрывать числа на засечках или показывать
let rand = getSelectedPreferenceFromList(key, preference);
```

Примеры работы с двумя независимыми `preference`:
`zdn/matege2024b/15/506736.js`, `zdn/matege2024b/4/513771.js`, `zdn/matege2022p/9/509192.js`.
